## 一、概述

「我要干饭」是面向 HP 公司约 20 名同事的午饭点餐小程序，基于 **uni-app + Vue3 + TypeScript + 微信云开发** 实现。

- **应用名**：我要干饭（导航栏标题）
- **当前模式**：多组织；`GROUP_ID = 'lunch_hp'` 仅默认回退，可在选组页切换
- **云环境**：`cloud1-d0g9zww8h390b6f41`
- **数据隔离**：所有集合/云函数/存储路径以 `lunch_` 前缀隔离，可与账本共用同一云环境

核心流程：成员在菜单页点餐 → 管理员在管理页批量确认 → 生成确认单下载 → 月度统计自动聚合。

## 二、程序模式与切换

### 2.1 当前模式：始终支持多组织

当前代码没有 `APP_MODE` 开关，也不存在“HP 专用 / 通用模式”二选一：

| 场景 | 行为 |
|------|------|
| 无本地会话 | 进入选组页，可创建组织、按组名加入、进入已加入组织 |
| 已有会话 | 进入当前激活组织 |
| 默认组 | `lunch_hp`，仅作为 `groupId` 回退值，不是强制入口 |

### 2.2 切换组织

**入口**：首页右上角组织名/头像区域 → 跳转选组页。

选组页支持：
- 点击“我的组织”中的组织直接进入
- 输入组织名称加入（`joinGroupByName`）
- 输入新名称创建组织（`createGroup`，组名全局唯一）

### 2.3 切换操作步骤

1. 首页点击右上角组织区域 → `reLaunch` 到选组页
2. 在选组页选择目标组织，或输入名称加入/创建

当前代码的真实调用链（`pages/group-select/index.vue` 的 `switchToGroup`）：

```
clearFreshnessCache()
clearAllCache()                 // 清所有缓存 + session，_cacheGeneration++
resetStore()
setActiveGroupId(targetGroupId) // 写 lunch_active_group_id，同时 setStore(groupId)
resetInit()
await startInit()               // lunch_menu.initGroup：只校验组织存在
await menuAction('joinGroup')   // 创建/取回目标组织的 member
setStore(member/role/groupId)
saveSession(...)
switchTab 首页
  → 首页 onShow：启动 watchTodayOrders + checkDataFreshness(getDataTimestamps)
```

关键结论：

- 主动切换是 **`initGroup → joinGroup → 首页 freshness（getDataTimestamps）`**。
- 主动切换**不调用 `getInitData`**；`getInitData` 只用于冷启动时 store 里没有 member（内部会内联 join），以及恢复备份后的重新加载。
- `lunch_active_group_id` 在清空旧缓存之后、`initGroup` 之前写入。
- 旧 session 随 `clearAllCache()` 删除；新 session 在 `joinGroup` 成功后保存。
- 旧组织的 watch 依赖首页离开时 `onHide → closeAll()` 关闭；group-select 流程本身不持有 watch。
- 旧组织已经排队的缓存写入通过 `_cacheGeneration` + `groupId` 双校验丢弃，避免延迟回写新组织缓存。

### 2.4 切换后的影响

| 项目 | 影响 |
|------|------|
| 本地缓存 | 全部清空（订单、菜单、成员、统计、会话） |
| 当前用户角色 | 在目标组中重新加入，默认为 `member`；若已是该组 creator 则保留 |
| 历史数据 | 不受影响，原组织数据保留在云端，按 `groupId` 隔离 |
| 其他用户 | 不受影响，仍在各自激活的组织中 |
| 云函数 | 无需重新部署，自动按传入的 `groupId` 处理 |

### 2.5 注意事项

- 切换组织是**本机行为**，只影响当前设备的当前微信账号
- 组织不存在时不会被自动创建；需要先在选组页创建
- 创建者可在管理页“危险操作”中删除整个组织，删除不可恢复

## 三、角色与权限

系统内置三种角色，定义于 [src/constants/orderStatus.ts](../src/constants/orderStatus.ts)：

| 角色 | 标识 | 获取方式 | 权限 |
|------|------|----------|------|
| 创建者 | `creator` | 创建组织的人 | 全部权限，含设/撤管理员、清空数据、删除组织 |
| 管理员 | `admin` | 由创建者任命 | 菜单管理、订单确认/取消、统计、管理页 |
| 普通成员 | `member` | 默认 | 点餐、查看首页、编辑自己姓名 |

> 普通成员也可以点击“＋新增同事”创建虚拟成员（不限管理员）。

**底部 TabBar 可见性**（见 [CustomTabBar.vue](../src/components/CustomTabBar/CustomTabBar.vue)）：

- `creator` / `admin`：首页、菜单、统计、管理（4 个 Tab）
- `member`：首页、菜单（2 个 Tab，统计/管理页强制跳转回首页）

## 五、终端用户操作指南

### 5.1 首次进入

1. **选组页**：无本地会话时先进入选组页，创建组织、按组名加入或进入已加入组织。组织需由 `createGroup` 创建，`initGroup` 不会自动建组。
2. **隐私协议**：进入组织后首次弹出隐私协议弹窗，点击「同意并继续」进入；点击「不同意」则退出小程序。
3. **欢迎弹窗**：输入姓名（选填），点击「确认」保存，或「跳过」稍后设置（跳过会写入“用户{时间戳}”）。

### 5.2 首页

**界面元素**（[pages/home](../src/pages/home/index.vue)）：

- 顶部：标题「🍚 我要干饭」+ 当天日期；右侧头像（姓名首字）+ 显示名 + 组织名
- 统计卡片：月点单数（橙色）、今日点单数（蓝色），均为**数量**，不是金额
- 今日点单列表：按状态分组显示
  - 已确认（绿色标签，✅）
  - 待确认（橙色标签，⏳）
  - 已取消（灰色，删除线）
- 截止提示：每天到停止接单时间后，显示“每天HH:MM停止接单，有需要请电话联系”，次日 0 点自动消失

**操作**：

| 操作 | 说明 |
|------|------|
| 点击右上角头像/姓名 | 弹出姓名编辑框，可修改自己的姓名 |
| 下拉刷新 | 重新拉取今日数据 |
| 取消自己的待确认订单 | 列表中自己的待确认订单显示「取消」按钮，点击直接取消 |
| 申请取消自己的已确认订单 | 已确认订单显示「申请取消」按钮，提交后进入管理员审批流程；审批中显示「申请中」；被拒绝显示「拒绝取消」 |

**虚拟成员绑定**：当前是手动关联。首页点击右上角头像/姓名 → 姓名弹窗中“关联已有记录”→ 选择虚拟成员；或在管理页成员管理中由管理员把虚拟成员关联到某个已登录微信成员。登录时不会自动弹出同名匹配确认框。

### 5.3 菜单页（点餐）

**界面元素**（[pages/menu](../src/pages/menu/index.vue)）：

- 顶部 tab 栏：`常点 | 全部 | 供应商...`（[MenuFilter.vue](../src/components/menu/MenuFilter.vue)）
  - **常点**：个人常点优先，不足 9 个用大众常点补齐，平铺不分组，最多显示 9 个
  - **全部**：所有可见菜品，按最近点餐时间（LRU）→ 频率 → sortNo 排序
  - **供应商 tab**：按供应商分组，tab 顺序按该供应商最近被点餐时间降序
- 菜单列表：仅显示「可见」菜品（菜名 + 供应商；普通菜单页**不显示价格**）
- 底部点餐栏：已选菜品名 + 「为自己点 / 帮人点」切换 + 提交/语音按钮

**「常点」tab 规则**（[useMenuFilter.ts](../src/hooks/useMenuFilter.ts)）：

- **个人常点**：当前用户点过的菜（`userCount > 0`），按最近点餐时间降序（LRU，不看频率，新菜点一次即进）
- **大众常点补齐**：个人常点不足 9 个时，用其他同事点过的菜（`orderCount > 0`）按最近点餐时间降序补齐，没被任何人点过的菜不补
- **上限**：最多 9 个（个人常点在前，逐步取代大众常点）
- **默认 tab**：进入菜单页默认选中「常点」；没有常点记录时显示“暂无常点记录”，可切到“全部”
- **帮他人点餐**：切换到「帮人点」并选择同事后，「常点」tab 自动按被帮人的个人统计排（拉取被帮人的 `lunch_user_menu_stats`）

**点餐流程**：

1. 通过 tab 切换、筛选或语音找到目标菜品，点击选中（底部显示菜品名）
2. 选择「为自己点」或「帮人点」
   - 帮人点：弹出成员选择器，选择同事；或点击「＋新增同事」创建虚拟成员
3. 点击「提交点餐」提交，订单状态为「待确认」

**语音搜索**：

- 未选菜品时，底部按钮显示「点击说话」
- 点击开始录音，再次点击结束；识别中显示「识别中...」
- 识别结果优先反向匹配菜单名（菜名出现在文本中即命中），否则用关键词模糊匹配
- 录音过程显示底部波形面板

## 六、管理员操作指南

> 以下功能仅 `creator` / `admin` 可见。普通成员访问统计/管理页会被强制跳转回首页。

### 6.1 统计页

**界面元素**（[pages/stats](../src/pages/stats/index.vue)）：

- 汇总卡片：总金额、总单数
- 柱状图：按月度展示金额；下方有“下载月度数据”按钮
- 饼图：按供应商占比
- 明细列表：分页加载已确认订单
- 右下角浮动「筛选」按钮（有激活筛选时变橙色）

**操作**：

| 操作 | 说明 |
|------|------|
| 点击筛选浮按 | 打开筛选面板（年份、月份、成员、供应商多选） |
| 应用/重置筛选 | 重新加载统计与详单；有筛选时由后端实时聚合同口径汇总 |
| 点击“下载月度数据” | 下载当前筛选范围的月度聚合 CSV |
| 下拉刷新 | 强制重新加载统计 |

### 6.2 管理页

管理页是一个长滚动页面，从上到下依次为以下模块（[pages/data](../src/pages/data/index.vue)）：

#### 6.2.1 停止接单时间

- 显示当前截止时间（默认 `10:00`）
- 「修改时间」：选择每天截止时间，保存后自动启用
- 「禁用 / 启用」：禁用后到点不截止点餐、不显示首页提示
- 首页在截止后到当日 24:00 自动显示“每天HH:MM停止接单，有需要请电话联系”
- 普通成员截止后提交会被拒绝；管理员/创建者不受限制

#### 6.2.2 待确认订单

- 列出当日待确认订单，支持单选/全选
- 「批量确认」：选中订单状态变为已确认
- 「批量取消」：选中订单状态变为已取消
- 可展开历史待确认订单，分页加载

#### 6.2.3 取消申请列表

- 展示已确认订单的取消申请
- 「批准」：订单变为已取消
- 「拒绝」：订单保持已确认，申请人首页显示「拒绝取消」

#### 6.2.4 已确认订单

- 列出当日已确认订单，支持单选/全选
- 「批量取消」：选中订单变为已取消
- 「下载」：弹出下载对话框，可选「按供应商分别下载」或「一并下载」生成确认单
- 可展开历史已确认订单，分页加载

#### 6.2.5 成员管理

- 查看所有成员列表
- 「改名」：修改成员姓名（虚拟成员可「与微信账号合帐」）
- 「设为管理员 / 撤销管理员」：仅 creator 可操作
- 「删除成员」：移除成员（creator 不可删除自己）

#### 6.2.6 菜单管理

- 查看全部菜品（含隐藏项）
- 「添加菜品」：填写供应商、餐品名、价格
- 「编辑 / 删除」菜品
- 「切换可见/隐藏」：隐藏后普通成员点餐时看不到
- 「按供应商批量显隐」：整组切换
- 当前没有“上移 / 下移”按钮；排序由可见分组、最近点餐时间、点餐次数和 sortNo 共同决定

#### 6.2.7 导入导出

- **导出**：可选导出订单/菜单/成员数据
- **导入**：可选导入订单/菜单/成员，支持 `csv`、`xlsx` 格式
- 导入方式：追加（重复跳过）或清库重写
- 订单导入在云函数内一次完成；菜单/成员 CSV 数据量大时前端会按 400KB/2000 条分批

#### 6.2.8 数据备份

- 「立即备份」：创建手动备份
- 「恢复备份」：三步流程
  1. **选择备份**：列表展示自动备份（🟢）和手动备份（🔵），含时间、订单/菜品/成员数量
  2. **备份预览**：查看类型、时间、数量、数据范围、备注
  3. **确认恢复**：先创建安全快照，再开始分片恢复；恢复期间组织进入维护状态，失败后可选择同一备份继续

#### 6.2.9 订单关联修复

- 覆盖导入人员或菜单后，「最近点过」排序异常时可点击“重置订单关联”
- 云函数按成员姓名、供应商+菜名重新匹配订单的 `memberId/menuId`，并清空个人点餐统计（下次点餐自动重建）

#### 6.2.10 危险操作（仅创建者）

- 「删除数据」：清空当前组订单、菜单、非创建者成员、统计、审计日志和下单锁，并刷新数据时间戳，其他成员端会重新加载
- 「删除组织」：删除组织及全部数据（含备份记录/文件、下单锁；头像等文件仅在其他组织无引用时删除），输入“删除”二次确认后执行，不可恢复
- 两个按钮对非创建者禁用

## 七、部署指南

### 7.1 前置条件

- 微信开发者工具
- 已注册微信小程序，获取 AppID
- 已开通微信云开发环境

### 7.2 首次部署步骤

1. **修改 AppID**：编辑 [src/manifest.json](../src/manifest.json)，填入小程序 AppID
2. **配置云环境**：确认 [src/constants/appConfig.ts](../src/constants/appConfig.ts) 中 `CLOUD_ENV` 为目标云环境 ID
3. **安装依赖**：
   ```bash
   npm install
   ```
4. **部署云函数**：在微信开发者工具中，右键 `wxcloud/functions/` 下四个云函数（`lunch_menu`、`lunch_order`、`lunch_backup`、`lunch_voice`），选择「上传并部署：云端安装依赖」；`lunch_backup` 还需上传定时触发器配置
5. **初始化数据**：首次打开进入选组页，由用户创建组织（`createGroup`）；`initGroup` 只校验组织存在，不会自动建组
6. **本地预览**：
   ```bash
   npm run dev:mp-weixin
   ```
   在微信开发者工具打开 `dist/dev/mp-weixin` 目录预览
7. **生产构建**：
   ```bash
   npm run build:mp-weixin
   ```
   通过微信开发者工具上传发版

### 7.3 云环境切换（测试 ↔ 生产）

只需修改 [src/constants/appConfig.ts](../src/constants/appConfig.ts) 的 `CLOUD_ENV` 一个配置项，无需改代码：

- 测试阶段：填独立测试环境 ID
- 生产阶段：填账本共用环境 ID（通过 `lunch_` 前缀隔离）

### 7.4 切换组织

参见 [第二章](#二程序模式与切换)。

## 八、开发与二次开发

### 8.1 技术栈

- **框架**：uni-app（Vue 3 + TypeScript）
- **云开发**：微信云开发（TCB），云函数 Node.js
- **状态管理**：自研轻量 reactive store（[src/services/store.ts](../src/services/store.ts)）
- **数据层**：[src/services/repositories/baseRepository.ts](../src/services/repositories/baseRepository.ts) 封装云函数调用

### 8.2 目录结构

```
src/
├── components/          # 组件（按页面分组）
│   ├── CustomTabBar/    # 自定义底部导航
│   ├── home/            # 首页组件
│   ├── menu/            # 菜单页组件
│   ├── stats/           # 统计页组件
│   └── data/            # 管理页组件
├── constants/           # 配置常量

│   ├── cacheConfig.ts   # 缓存键与 TTL
│   └── orderStatus.ts   # 角色与订单状态枚举
```

### 8.6 二次开发注意事项

- **改 `GROUP_ID` 默认值必须同步改 4 处**（前端 1 + 云函数 main 回退 3），否则默认组织不一致；运行时可切换组织，不依赖这个默认值
- 新增云函数 action 时，在对应云函数 `handlers` 对象中注册
- 前端调用云函数统一走 `baseRepository` 的 `menuAction` / `orderAction` / `backupAction` 封装

- 新增会修改数据的操作时，确认是否更新 `ordersTimestamp` / `menuTimestamp` / `membersTimestamp` / `dataTimestamp`，以及是否需要按月份 rebuild

## 九、常见问题

**Q1：普通成员看不到统计和管理页？**
A：正常。`member` 角色只有首页和菜单两个 Tab，访问统计/管理页会被强制跳转回首页。需 creator 任命为 admin。

**Q2：如何成为管理员？**
A：只有 creator 能任命。creator 在管理页 → 成员管理 → 点击成员「设为管理员」。

**Q3：已确认订单还能取消吗？**
A：可以。成员在首页对自己已确认订单点「申请取消」，管理员在管理页「取消申请列表」中审批。审批通过才真正取消。

**Q4：帮没注册的同事点餐怎么办？**
A：菜单页选「帮人点」→「＋新增同事」→ 输入姓名创建虚拟成员，即可代点。该同事后续登录后，可在首页姓名弹窗“关联已有记录”，或在管理页由管理员把虚拟成员关联到其微信成员；不会在登录时自动匹配。

**Q5：停止接单时间怎么改 / 关掉？**
A：管理页 → 停止接单时间 →「修改时间」或「禁用」。禁用后到点不截止点餐，也不显示首页提示。

**Q6：误删数据能恢复吗？**
A：可以。管理页 → 数据备份 → 恢复备份，选择误操作前的自动/手动备份。恢复前系统会自动创建安全快照；恢复期间组织进入维护状态，失败可选择同一备份继续。

**Q7：能不能一套代码给多个公司用？**
A：可以。当前始终支持多组织：首页右上角进入选组页，创建新组织或输入名称加入；数据按 `groupId` 隔离，互不影响。详见 [第二章](#二程序模式与切换)。

**Q8：切换云环境会丢数据吗？**
A：不会。切换云环境只是连接到不同环境，原环境数据保留。但注意不同环境的数据不互通。

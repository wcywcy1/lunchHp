# 我要干饭 — HP 午饭点餐小程序方案（需求与设计）

> 全局常量速查表见 [30.6-公司午饭点餐小程序方案.md](30.6-公司午饭点餐小程序方案.md)

## 一、需求总览

| 项目 | 说明 |
|------|------|
| 名称 | 我要干饭 |
| Logo | `docs/hp logo.png` |
| 用户 | HP 公司约 20 名同事 |
| 场景 | 每天午饭点餐，管理员确认后下单 |
| 入组 | 打开即进，自动加入点餐组（groupId=lunch_hp 写死），首次弹出姓名输入框（可跳过） |
| 数据隔离 | 与账本共用 TCB 环境，所有集合/云函数/存储路径以 `lunch_` 前缀隔离 |

### 核心功能

| 模块 | 功能 | 说明 |
|------|------|------|
| **用户进入** | 打开即进 | 自动加入点餐组（groupId=lunch_hp 写死），首次弹出姓名输入框（可跳过） |
| **首页** | 当日日期 | 显示年月日 |
| **首页** | 月度汇总 | 当月总金额 |
| **首页** | 当日点单 | 显示当日点单明细 + 状态标签（待确认/已确认） |
| **首页** | 个人信息 | 点击右上角头像/姓名 → 弹出编辑自己姓名的弹窗 |
| **菜单页** | 餐品列表 | 序号、供应商、餐品、价格、照片(可选)、可见/隐藏状态 |
| **菜单页** | 表头筛选 | 供应商/餐品名筛选，联动过滤可选项 |
| **菜单页** | 点餐下单 | 选择菜品提交，提交后不可自行修改；仅显示可见菜品 |
| **菜单页** | 帮人点餐 | 可选择同事代为下单，所有人可用 |
| **菜单页** | 菜单编辑（管理员） | 添加/编辑/删除/上下移动/切换可见，普通用户不可见 |
| **统计页** | 年度/月度统计 | 柱状图（带金额标签）+ 供应商占比饼图（带金额） |
| **统计页** | 筛选 | 年份 + 月份 + 点餐人 + 供应商 |
| **统计页** | 筛选详单 | 年月日\|姓名\|餐品\|金额\|供应商 |
| **统计页** | 柱状图下载 | 分月聚合数据可下载 |
| **数据页** | 订单管理（管理员） | 待确认列表 + 批量确认；已确认列表按供应商分组 |
| **数据页** | 成员管理（管理员） | 查看成员列表，编辑任意成员姓名，设置管理员 |
| **数据页** | 下载确认单（管理员） | 已确认订单下载，可选按供应商分文件或一并下载 |
| **数据页** | 导入导出（管理员） | 导出清单：日期\|菜品\|姓名\|金额\|备注 |
| **权限** | 数据页仅管理员可见 | 点餐者 TabBar 不显示数据页 |

## 二、权限模型

```
角色：
├── 创建者（建组人）       → 全部权限 + 可指定管理员
├── 管理员（创建者指定）   → 菜单编辑 + 订单管理 + 统计 + 下载 + 导入导出
└── 点餐者                → 看菜单 + 下单 + 看统计
```

| 操作 | 创建者 | 管理员 | 点餐者 |
|------|:------:|:------:|:------:|
| 查看菜单 | ✅ | ✅ | ✅ |
| 点餐下单 | ✅ | ✅ | ✅ |
| 帮人点餐 | ✅ | ✅ | ✅ |
| 修改自己未提交订单 | ✅ | ✅ | ✅ |
| 修改自己已提交订单 | ✅ | ✅ | ❌ 提示"已提交，请联系管理员" |
| 编辑自己的姓名 | ✅ | ✅ | ✅ 首页右上角点击头像/姓名 |
| 菜单增删改+排序 | ✅ | ✅ | ❌ 按钮不可见 |
| 菜单切换可见/隐藏 | ✅ | ✅ | ❌ 不可见菜品完全不显示 |
| 查看统计页 | ✅ | ✅ | ✅ |
| 批量确认订单 | ✅ | ✅ | ❌ |
| 下载确认单 | ✅ | ✅ | ❌ |
| 修改/删除他人订单 | ✅ | ✅ | ❌ |
| 编辑他人姓名 | ✅ | ✅ | ❌ |
| 导入导出 | ✅ | ✅ | ❌ |
| 指定管理员 | ✅ | ❌ | ❌ |
| **访问数据页** | ✅ | ✅ | ❌ **TabBar 不可见** |

## 四、数据模型

### 4.1 lunch_groups（点餐组）

> 当前只有一组，`_id = "lunch_hp"` 写死。保留表结构以便未来扩展多组。
> 首次打开小程序时，`initGroup` 云函数自动检测并创建该记录，无需手动初始化。

```
_id               // 固定 "lunch_hp"（写死）
name              // 组名，如"HP午饭"
creatorId         // 创建者 openid
qrcode            // 入口二维码场景值（保留，暂不使用）
createdAt         // 创建时间
```

### 4.2 lunch_members（成员）

```
_id
groupId           // 所属组
name              // 姓名（用户输入，可为空）
nickName          // 微信昵称（自动获取，name为空时的显示名）
avatar            // 头像 fileID（云存储路径，用户主动选择后上传）
openid            // 微信 openid（虚拟成员为空，登录后补上）
role              // creator / admin / member
isVirtual         // 是否虚拟成员（true=帮人点餐时创建，无openid / false=已登录）
privacyAgreed     // 是否同意隐私协议（true=已同意 / false=未同意，避免重复弹窗）
joinedAt          // 加入时间
```

**姓名显示规则：**
- `name` 有值 → 显示 `name`
- `name` 为空 → 显示 `nickName`（微信昵称）
- 前端统一用 `displayName = name || nickName`

**虚拟成员规则：**
- 帮人点餐时 [＋新增同事] 创建的成员，`openid` 为空，`isVirtual = true`
- 虚拟成员在成员列表中显示灰色标记"未登录"
- 虚拟成员绑定微信有两个入口（所有人可用，不限管理员）：
  - **入口1：登录时自动匹配** — `joinGroup` 按 name 精确匹配虚拟成员，弹出确认弹窗
  - **入口2：首页手动关联** — 点击右上角头像/姓名 → 弹窗中增加"关联已有记录"选项

**虚拟成员绑定流程（入口1 — 自动匹配）：**
- 打开小程序时，`joinGroup` 检测到同名虚拟成员（name 精确匹配）
- 弹出确认弹窗：
  ```
  ┌─────────────────────────┐
  │  关联点餐记录            │
  │                          │
  │  是否关联到之前"张三"的  │
  │  点餐记录？              │
  │                          │
  │  [否，创建新成员] [是，关联]│
  └─────────────────────────┘
  ```
- 选"是" → 补上 `openid`、`nickName`，`isVirtual` 改为 `false`，历史订单自动关联
- 选"否" → 创建新成员，不合并

**虚拟成员绑定流程（入口2 — 手动关联）：**
- 首页右上角点击头像/姓名 → 弹窗底部增加"关联已有记录"按钮
- 点击后显示所有虚拟成员列表，选择一个 → 弹出确认弹窗（同上）
- 适用场景：登录时名字没匹配上（如虚拟成员叫"张三"，自己输入了"张三丰"），后来自行关联

**头像处理（与账本一致）：**
- 微信已废弃 `wx.getUserProfile`，无法自动获取微信头像
- 使用 `<button open-type="chooseAvatar" @chooseavatar="onChooseAvatar">` 方式
- 用户主动点击"选择微信头像"按钮 → 获取临时路径 → 上传到云存储 `lunch/avatar/` 目录 → 存储 fileID
- 未设置头像时，显示姓名首字的彩色圆形占位符（与账本 MemberManageModal 一致）

**菜单照片上传流程：**
- 管理员添加/编辑菜品时，可点击"添加照片"按钮
- 调用 `wx.chooseMedia` 选择图片 → 获取临时路径
- 上传到云存储 `lunch/photos/` 目录（文件名格式：`menu_{timestamp}_{random}.jpg`）
- 存储 fileID 到 `lunch_menu.photo` 字段
- 删除菜品时，同时调用 `wx.cloud.deleteFile` 删除对应云存储文件
- 照片为可选项，`photo` 字段为空时不显示图片

### 4.3 lunch_menu（菜单）

```
_id
groupId           // 所属组
sortNo            // 序号（排序用，整数，间距10便于插入）
supplier          // 供应商
name              // 餐品名
price             // 价格（数字）
photo             // 照片 fileID（可选，为空则不显示）
visible           // 是否可见（true=可见 / false=隐藏，管理员可切换）
createdAt         // 创建时间
```

**visible 字段规则：**
- `true`：所有用户可见可点
- `false`：仅管理员可见，显示在可见菜品下方，灰色标记
- 管理员可将可见菜品设为不可见，也可将不可见菜品恢复为可见
- **不可见菜品永远排在可见菜品下方**，上移操作不可跨越可见/不可见分界线

### 4.4 lunch_orders（订单）

```
_id
groupId           // 所属组
date              // 日期 "2026-06-16"
memberId          // 下单人ID
memberName        // 下单人姓名（冗余）
menuId            // 菜品ID
menuName          // 菜品名（冗余）
supplier          // 供应商（冗余，方便按供应商分组+下载）
price             // 金额
note              // 备注
status            // pending=待确认 / confirmed=已确认 / cancelled=已取消
createdAt         // 下单时间
confirmedAt       // 确认时间
```

### 4.5 lunch_monthly_stats（月度聚合统计，大数据量时启用）

```
_id               // groupId_2026_06
groupId           // 所属组
year              // 年份
month             // 月份
totalAmount       // 月总金额
orderByMember     // { "张三": 560, "李四": 420, ... }
orderBySupplier   // { "老王": 880, "小李": 640, ... }
orderByMenu       // { "红烧肉": 360, "宫保鸡丁": 320, ... }
orderCount        // 订单数
updatedAt         // 更新时间
```

## 五、订单状态机

```
                    点餐者提交
  （未下单） ──────────────▶ pending（待确认）
                                 │
                    管理员确认    │    管理员取消
                 ┌───────────────┘──────────────┐
                 ▼                              ▼
          confirmed（已确认）           cancelled（已取消）
```

- 点餐者提交后**不可自行修改或撤回**，提示"已提交，请联系管理员"
- 管理员可批量确认 pending 订单
- 管理员可修改/取消任意订单

## 六、页面设计

### 6.1 首页

```
┌─────────────────────────────┐
│  🍚 我要干饭        张三 👤 │  ← 点击头像/姓名 → 编辑姓名弹窗（头像可点击更换）
│  2026年06月16日              │  ← 年月日
│                              │
│  ┌──────────┐ ┌──────────┐  │
│  │  月合计   │ │  今日    │  │
│  │  ¥856    │ │  ¥42     │  │
│  └──────────┘ └──────────┘  │
│   ↑云端聚合     ↑本地计算     │
│   getInitData   recentOrders │
│   monthSummary  按今日过滤    │
├──────────────────────────────┤
│  今日点单                     │
│  ┌────────────────────────┐ │
│  │ 张三  红烧肉    ¥18  ⏳│ │  ← ⏳待确认（橙色）
│  │ 李四  宫保鸡丁  ¥16  ✅│ │  ← ✅已确认（绿色）
│  │ 王五  鱼香肉丝  ¥18  ✅│ │
│  └────────────────────────┘ │
├──────────────────────────────┤
│  [首页]  [菜单]  [统计]  [数据]│  ← 管理员4个Tab
└──────────────────────────────┘
```

**右上角头像/姓名交互：**
- 显示 `displayName`（name 有值显示 name，否则显示微信昵称）
- 点击后弹出编辑姓名弹窗：
  ```
  ┌─────────────────────────┐
  │  修改姓名                │
  │                          │
  │  当前：张三              │
  │  新姓名：[________]      │
  │                          │
  │  [取消]    [保存]         │
  │                          │
  │  ── 或 ──                │
  │  [🔗 关联已有记录]       │  ← 仅当存在虚拟成员时显示
  └─────────────────────────┘
  ```
- 保存姓名 → 调用 `updateMemberName`，更新本地缓存 + 云端
- 点击"关联已有记录" → 显示虚拟成员列表 → 选择后弹出确认弹窗

**首次入组交互：**
- 打开小程序后，自动调用 `joinGroup` 创建成员记录（groupId=`lunch_hp` 写死；nickName 自动获取，`privacyAgreed=false`）
- **隐私协议确认**（仅 `privacyAgreed=false` 时弹出，同意后不再重复）：
  ```
  ┌─────────────────────────┐
  │  隐私协议                │
  │                          │
  │  使用本小程序前，请阅读   │
  │  《隐私保护指引》         │
  │                          │
  │  [不同意]    [同意并继续] │
  └─────────────────────────┘
  ```
  - 点击"同意并继续" → 更新 `privacyAgreed=true`，继续下一步
  - 点击"不同意" → 退出小程序（`wx.exitMiniProgram`）
  - 后续每次进入，若 `privacyAgreed=true` 则跳过此弹窗
- 紧接着弹出姓名输入弹窗（可跳过）：
  ```
  ┌─────────────────────────┐
  │  欢迎加入！              │
  │                          │
  │  请输入你的姓名（选填）   │
  │  [________________]      │
  │                          │
  │  不填将使用微信昵称       │
  │                          │
  │  [跳过]    [确认]         │
  └─────────────────────────┘
  ```
- 跳过 → `name` 为空，显示 `nickName`
- 填写 → `name` 为输入值，显示 `name`

点餐者只有 3 个 Tab：`[首页]  [菜单]  [统计]`

### 6.2 菜单页 — 点餐者视角

```
┌─────────────────────────────┐
│  今日菜单                    │
│  ┌────────────────────────┐ │
│  │ 供应商 [全部 ▼] 餐品 [全部▼]│ │  ← 表头筛选
│  └────────────────────────┘ │
├────┬──────┬────────┬────┐   │
│ #  │ 供应商│  餐品   │ 价格│   │
├────┼──────┼────────┼────┤   │
│ 1  │ 享德来│ 雞腿飯  │ 27 │ ○ │
│ 2  │ 享德来│ 香腸飯  │ 27 │ ● │  ← 已选高亮
│ 3  │ 谷田稻│ 黑胡椒牛│ 37 │ ○ │
│ 4  │ 可乐  │ 可乐   │  3 │ ○ │
└────┴──────┴────────┴────┘   │
│                              │
│  已选：香腸飯 ¥27            │
│  为自己点 | 帮[选择同事▼]点   │  ← 切换为自己/帮人点
│  [提交点餐]                   │
└─────────────────────────────┘
```

**注意：** 点餐者只能看到 `visible=true` 的菜品，不可见菜品完全不显示。

**帮人点餐规则：**
- 所有人都可以帮人点餐（20人小团队，互相帮忙很常见）
- 默认"为自己点"，点击"帮[选择同事▼]点"后弹出成员列表，选择一位同事
- 选定后，点餐栏显示"帮 王五 点"，提交的订单 memberName 为"王五"
- 帮人点的订单，该同事自己无法修改/撤回（与正常提交一样，提示"已提交，请联系管理员"）
- 可以连续帮多人点：帮A点完后，切换到帮B点
- **同事不在列表中**：成员列表底部有 [＋新增同事] 按钮，输入姓名即可创建虚拟成员（无 openid），立即可以帮其点餐
- **虚拟成员后来自行登录**：见数据模型中"虚拟成员绑定流程"说明

**表头筛选联动规则：**
- 选了供应商"享德来" → 餐品下拉只显示享德来的菜品
- 选了餐品"雞腿飯" → 供应商自动锁定为"享德来"
- 选"全部" → 恢复完整列表
- 筛选只影响显示范围，不影响已选项（若已选的菜品不在筛选结果中，仍保留在已选区）

### 6.3 菜单页 — 管理员视角

```
┌─────────────────────────────┐
│  今日菜单              [＋]  │  ← 添加按钮
│  ┌────────────────────────┐ │
│  │ 供应商 [全部 ▼] 餐品 [全部▼]│ │
│  └────────────────────────┘ │
├────┬──────┬────────┬────┬──┐│
│ #  │ 供应商│  餐品   │ 价格│操││
├────┼──────┼────────┼────┼──┤│
│    │ ── 可见菜品 ──────── ││  ← 分隔线
│ 1  │ 享德来│ 雞腿飯  │ 27 │⬆⬇││
│ 2  │ 享德来│ 香腸飯  │ 27 │✏👁││  ← 👁=点击隐藏
│ 3  │ 谷田稻│ 黑胡椒牛│ 37 │⬆⬇││
│ 4  │ 可乐  │ 可乐   │  3 │✏🗑││
│    │ ── 已隐藏（2）▶ ──── ││  ← 默认折叠，点击展开
└────┴──────┴────────┴────┴──┘│
│                              │
│  已选：香腸飯 ¥27            │
│  为自己点 | 帮[选择同事▼]点   │  ← 管理员也能点餐+帮人点
│  [提交点餐]                   │
└─────────────────────────────┘
```

- 可见菜品区：⬆上移 ⬇下移 ✏编辑 🗑删除 👁隐藏
- 已隐藏菜品区：**默认折叠**，显示"── 已隐藏（N）▶ ──"，点击后展开显示隐藏菜品列表（灰色背景），再点收起
- 展开后每行操作：👁恢复可见 ✏编辑 🗑删除
- **不可见菜品永远排在可见菜品下方**，上移操作不可跨越分界线
- 右上角 [＋] 添加菜品，新添加的菜品默认可见
- 排序通过修改 sortNo 实现，上移=与前一条交换 sortNo，下移=与后一条交换 sortNo

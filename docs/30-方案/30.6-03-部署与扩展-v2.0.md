## 十六、隔离保障

### 16.1 环境策略

**当前生产环境：**
```
CLOUD_ENV = 'cloud1-d0g9zww8h390b6f41'
```

点餐小程序与账本共用同一个 TCB 环境，通过 `lunch_` 前缀严格区分集合、云函数、存储路径。

### 16.2 命名隔离规则

| 资源类型 | 账本前缀 | 点餐前缀 |
|---------|---------|---------|
| 数据库集合 | 无前缀 | `lunch_` |
| 云函数 | `RevD_` | `lunch_` |
| 云存储路径 | `images/`, `exports/` | `lunch/` |
| localStorage 键 | `ledger_` | `lunch_` |

**硬性规定：**
- ❌ 点餐代码中绝不允许出现 `records`、`accounts`、`families` 等账本集合名
- ❌ 点餐代码中绝不允许出现 `RevD_` 开头的云函数名
- ❌ 点餐代码中绝不允许出现 `ledger_` 开头的 localStorage 键
- ✅ 所有点餐资源必须带 `lunch_` 前缀

### 16.3 云函数超时

所有点餐云函数 `config.json` 统一配置：
```json
{
  "timeout": 20
}
```

### 16.4 代码层面隔离

项目目录独立：
```
d:\family-ledger_RevB\Lunch_HP
```

| 隔离维度 | 机制 | 风险 |
|---------|------|------|
| 源代码 | 独立项目目录 | 零风险 |
| 小程序 | 不同 AppID | 零风险 |
| 数据库集合 | `lunch_` 前缀隔离 | 低风险 |
| 云函数 | `lunch_` 前缀隔离 | 低风险 |
| 云存储 | `lunch/` 路径隔离 | 低风险 |
| localStorage | `lunch_` 前缀 + 不同 AppID | 零风险 |

### 16.5 cloudClient 初始化

```typescript
// src/constants/appConfig.ts

```


## 十七、多租户与运行模式

### 17.1 两种运行模式

| 模式 | `APP_MODE` | 行为 |
|------|-----------|------|
| HP 专用 | `'hp'` | 固定加入 `lunch_hp`，无需选组 |
| 通用程序 | `'general'` | 支持创建/加入多个组织 |

### 17.2 HP 专用模式

```typescript
export const APP_MODE = 'hp' as 'hp' | 'general'
export const GROUP_ID = 'lunch_hp'
```

所有人直接进入 `lunch_hp` 组。

### 17.3 通用模式

将 `APP_MODE` 改为 `'general'` 后：

1. 启动页进入 `pages/group-select/index`
2. 用户可：
   - 查看已加入的组（`listJoinedGroups`）
   - 输入组名加入（`joinGroupByName`）
   - 创建新组（`createGroup`，组名全局唯一）
3. 选择组后写入 `lunch_active_group_id`
4. 所有云函数调用通过 `baseRepository.cloudAction` 自动注入当前 `groupId`

```typescript
// baseRepository.ts
const groupId = store.groupId || GROUP_ID
return wx.cloud.callFunction({
    name: cloudFuncName,
    data: { action, groupId, ...data },
})
```

### 17.4 历史数据安全

- 切换 `APP_MODE` 不会删除任何数据
- 所有数据查询都带 `groupId` 过滤
- 重新创建同名组通过 `groupId` 匹配恢复历史数据

## 十八、新项目启动指南

### 18.1 从现有项目部署的步骤

1. 确认 `src/constants/appConfig.ts` 中的 `CLOUD_ENV`
2. 部署 `wxcloud/functions/` 下所有云函数
3. 首次打开小程序时自动调用 `initGroup` 创建 `lunch_groups` 记录
4. 管理员录入菜单、指定管理员

## 十九、与 v1.0 的差异总结

| 项目 | v1.0 | v2.0 |
|------|------|------|
| 运行模式 | 单租户 lunch_hp | HP 模式 + 通用模式 |
| 实时同步 | 轮询 | watchTodayOrders 实时推送 |
| 取消机制 | 仅管理员 | 普通成员可申请/取消 |
| 月度统计 | 简单 rebuild | 增量刷新 + 并发锁定 |
| 语音 | 微信同声传译 | 腾讯云 ASR |
| 导入 | CSV | CSV + Excel |
| 通知 | 无 | 组通知公告 |
| 云函数超时 | 未明确 | 统一 20 秒 |
